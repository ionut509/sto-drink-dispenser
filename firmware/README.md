# Firmware ESP32

Acest director va găzdui codul sursă pentru `ESP32-WROOM-32`, incluzând:

- Access Point Wi-Fi local + portal captive / pagină web accesibilă prin cod QR
- Meniu de cocktailuri predefinite și selecție manuală a proporțiilor (în `ml`)
- Dozare calibrată pe canal (`ml/s` salvate în memorie nevolatilă)
- Protecție hardware prin microswitch de prezență pahar
- Pagină ascunsă de administrare (**Mod Service**: amorsare, calibrare 10s, spălare automată)

*Status: în curs de dezvoltare.*
