# Carcasă 3D (PETG) — Design „Șto”

Acest director va conține fișierele CAD (`.step` / `.f3d`) și modelele gata de printare (`.stl`) pentru:

- Carcasa principală în forma stilizată a lui **Șto**
- Compartimentul izolat pentru electronică (ESP32, drivere TB6612FNG, convertor Buck)
- Suporturile pentru cele 6 pompe peristaltice Kamoer 12V
- Suportul de pahar cu locaș pentru microswitch-ul de siguranță
- Canalul / colectorul comun pentru cele 6 duze de turnare

*Material recomandat: **PETG**.*
